# كوكب المناخ — V11 إعادة البناء الكاملة للواجهة

## ما الجديد؟

هذا تحديث للبنية البصرية والمعمارية للموقع بالكامل، وليس إعادة تلوين للقالب القديم.

- **التنقل:** شريط أقسام جانبي ثابت على الكمبيوتر، وشريط وصول سريع أسفل الهاتف مع قائمة أقسام شاملة. البحث ما زال متاحًا في أعلى الصفحة.
- **الرئيسية:** صفحة بأسلوب تحريري جديد، تعرض مدخلًا واضحًا للطقس والخرائط، دليلًا نصيًا للأقسام، موجز المدن، وآخر المقالات المنشورة من ملفات CMS الحقيقية، ومسارين منفصلين للفضاء وأرشيف القدس.
- **طقس المدن:** البحث واختيار المدينة أولًا، ثم بطاقة الحالة الحالية والقياسات، ثم التوقعات الساعية والأسبوعية، تليها المؤشرات والنصائح، وأخيرًا إنتاج بطاقة المشاركة.
- **الخرائط الجوية:** أدوات التحكم في عمود مستقل عن منطقة الخريطة على الكمبيوتر. على الهاتف تظهر الخريطة أولًا ثم الأدوات، لتقليل التشتيت.
- **المقالات:** قائمة تحريرية مرتبة ومباشرة مع مرشحات، وصفحات مقالات أُعيد تنسيقها مع فهرس محتويات ومؤشر تقدم القراءة.
- **الفضاء:** مستكشف النظام الشمسي أولًا، ثم مكتبة الأجرام والمقال العلمي جنبًا إلى جنب على الكمبيوتر، ثم أدوات المتحف الفلكي.
- **أرشيف القدس:** ملخص السجلات، ثم أبرز العواصف، ثم تصفح المواسم وفلاترها، ثم الإحصائيات والتحليل والمصادر.
- **الألعاب العلمية:** اختيار واضح بين اللعبتين ومنطقة لعب منفصلة مع تحسين وضوح نصوصها وأزرارها.
- **الهوية البصرية:** ورق فاتح محايد، لون حبر داكن، تدرج مرجعي محدود من ألوان الشعار، وعناوين أقل تزويقًا وأكثر ملاءمة لموقع منشور للجمهور.

## التثبيت الموصى به

1. احفظ نسخة احتياطية من مستودع GitHub الحالي أو أنشئ فرع `v11-rebuild-review`.
2. فك ضغط `Kawkab_AlMonakh_V11_Complete_Redesign_Upgrade.zip` محليًا.
3. انسخ **محتويات الحزمة** إلى جذر المستودع، واسمح باستبدال الملفات الثمانية المذكورة أعلاه فقط. لا ترفع ZIP كمجلد مغلق داخل GitHub.
4. نفّذ `npm run build:offline` و`npm test` محليًا إن أمكن، ثم `git add` و`commit` و`push` للفرع التجريبي.
5. تحقق من واجهات الهاتف والكمبيوتر وملفات خرائط GFS على نشر تجريبي قبل دمج الفرع في `main`.
6. بعد الدمج، سيبدأ Cloudflare بعملية البناء المعتادة وفق إعدادات الربط الحالية.

**تنبيه:** لا ترفع المشروع الكامل فوق المستودع الإنتاجي؛ استخدم حزمة الترقية فقط. المشروع الكامل مرجع مستقل لمن يريد قراءة الكود وتشغيل نسخة منفصلة.

## التشغيل والاختبارات

- بناء: `npm run build:offline`
- اختبارات البرمجة: `npm test`
- اختبارات المتصفح المحلي بدون اتصال خارجي: `npm run test:browser-layout`

نجح البناء، واختبار البنية والوظائف الأساسية للصفحات السبع على عرض 390 و1440 بكسل. اختبار المقارنة التاريخية القديمة مع مجلد V8 مستقل تم تخطيه لأن ذلك المجلد غير موجود في بيئة الاختبار الحالية. لا تدل هذه الاختبارات على نجاح جلب طقس حي أو نشر فعلي إلى Cloudflare.

نصوص المقالات وبيانات الأرشيف والفلك والطقس لم تُستبدل ببيانات تجريبية، ولم تُجرَ تغييرات على منطق خرائط النماذج الجوية. مسارات البيانات ووقت التوقع تبقى كما كانت في الإصدار العامل.
