# كوكب المناخ V11 — التصميم التحريري الجديد

## المبدأ

إعادة تصميم شاملة للواجهة وتجربة التنقل مع الحفاظ على وظائف الموقع الحالية، دون إعادة كتابة محرك البيانات الجوية أو خرائط GFS أو موسوعة الفضاء أو أرشيف القدس.

### 1. التصميم
- واجهة فاتحة محايدة بدل التدرجات اللامعة والبطاقات المتوهجة.
- لون أخضر بحري مستمد من الشعار، وخلفية ورقية هادئة ومساحات بيضاء واضحة.
- خطوط عربية مريحة، وتسلسل عناوين هادئ، وبطاقات معلومات أقرب إلى واجهات المواقع التحريرية العلمية.
- الرئيسية فيها خريطة تضاريسية حقيقية **كصورة خلفية فقط**، وليست خريطة توقعات رقمية.
- إعادة تصميم ترويسة الموقع، والقائمة على الهاتف، وتذييل الصفحات وصفحات المقالات المستقلة.

### 2. الوصول والتنقل
- سبعة أقسام واضحة بأسماء عربية مختصرة.
- بحث سريع من الترويسة عن الأقسام والمدن والمقالات المرفوعة، مع دعم Ctrl+K وEsc.
- شريط «انتقل إلى» داخل الأقسام الطويلة للذهاب مباشرة إلى أهم أجزاء الصفحة.
- روابط مباشرة من الرئيسية، وزر للعودة إلى أعلى الصفحة، ورابط تخطي القائمة لقارئ الشاشة.
- حالات تركيز واضحة وتحسينات عند تقليل الحركة في إعدادات الجهاز.

### 3. الاستمرارية
- أدوات الخرائط، صفحات المدن، مشهد الفضاء ثلاثي الأبعاد، بيانات الأرشيف، بطاقات الطقس والألعاب كلها باقية.
- حزمة الترقية **لا تشمل** `tools/` أو `.github/workflows/` أو `data/map-products/` ولا صور التوقعات.
- لا تستبدل تحديثات الخرائط العاملة في GitHub أو ملف الفهرس عند دمج هذه النسخة.
- الترويسة الجديدة تستخدم بحث V11 بدل واجهة البحث القديمة لتجنب تعارض الحدثين.

## التثبيت الآمن

1. أنشئ فرع مراجعة `v11-review` من حالة GitHub الحالية، واحتفظ بنسخة احتياطية.
2. **استخدم حزمة الترقية فقط** لا المشروع الكامل؛ قد يختلف خط الخرائط العامل على GitHub عن النسخة المحلية V10.
3. فك الضغط وارفع محتوياتها إلى جذر المستودع، مع المحافظة على المسارات.
4. نفّذ `npm run build:offline` ثم `npm run test:v11`، وتحقق من موقع Cloudflare التجريبي قبل الدمج.
5. لا تمسح أيًا من صور الخرائط المنشورة أو `catalog.json`.

## الاختبارات

- `npm run build:offline` لبناء V11 من الملفات الحالية دون الاتصال بالخارج.
- `npm run test:v11` لفحوصات بنية الأقسام والبحث والصفحات والملفات المحفوظة.
- اختبار Chromium بعرض 390px و1440px لنقل الصفحة والبحث والأرشيف والفضاء.

## الحدود

- تعديل التصميم لا يُنشئ بيانات طقس جديدة أو يضمن حداثتها؛ ما زالت خرائط GFS تعتمد على GitHub Actions التي أعددتموها.
- بعض مصادر الطقس والصور ثلاثية الأبعاد تحتاج اتصالًا بالإنترنت وقد تتأخر في بعض المتصفحات.
- مقتنيات V10 لم تُؤلّف من جديد؛ هذه نسخة تركّز على تنظيم عرض المحتوى لا زيادة حجمه.
- التعديل المنفصل لصفحات المقالات يحصل عبر `scripts/build.mjs` مع `v11-article.css`.
