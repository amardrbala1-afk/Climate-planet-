# كوكب المناخ V6 — إعادة بناء مُختبرة

هذه نسخة مستقلة قابلة للبناء والنشر على GitHub + Cloudflare Workers، مشتقة من V5 الأصلية وليست ترقيعًا فوق النسخة V6 السابقة.

## ما تم تنفيذه

1. **بطاقة الطقس اليومية فقط**: أزيل الاستوديو العام والملصقات العامة من الواجهة، وأُزيل كودها القديم غير المستخدم. عند اختيار مدينة وتاريخ من الأيام السبعة التي يعيدها مزود الطقس، تُرسم بطاقة PNG بدقة 1350×1080 بتوقعات ذلك التاريخ فقط. توجد ثلاثة مظاهر ألوان ومعاينة ذات حركة مطر/ثلج/سماء على الموقع؛ ملف PNG نفسه صورة ثابتة وليس GIF.
2. **هوية المدينة**: 18 اسم مدينة محدد لديه ملف رسم خاص سابقًا؛ بقية أسماء المدن تحصل على مشهد SVG مولّد بشكل حتمي ومختلف حسب الاسم والموضع، وليس صورة حقيقية أو معلمًا أثريًا موثقًا. المعالم الموثقة لكل مدينة من أصل 1000 **لم تُنجز**.
3. **الألعاب العلمية**: حُذفت لعبة الجيولوجيا من الواجهة والسكريبت. لعبة الفضاء حصلت على جرافيك Canvas أفضل (كواكب مضيئة، ألوان محيطية، سديم، حلقات زحل، كويكبات وسفينة)، ولعبة المتنبئ تحتوي 38 سؤالًا محررًا، منها 18 في الجولة المختلطة أو 12 في جولة المستوى، مع رسم وشرح للإجابة.
4. **خرائط النماذج**: بقيت خريطتا المستخدم التضاريسيتان داخل الموقع، مع مشروع نشر طبقات NOAA GFS على 500 hPa، 850 hPa، حرارة 2m والهطول، عبر `tools/publish_gfs.py` و`tools/fetch_gfs.py` و`tools/render_map.py`. يُمنع نشر طبقة ما لم تكن المعايرة وحقول GRIB والفترة صحيحة.
5. **المحتوى الأصلي محفوظ**: المقالات، موسوعة الفضاء، أرشيف القدس، خرائط المدن ونظام PWA.
6. **تحسين تجربة الواجهة**: اللغة أكثر رسمية، واستوديو الملصقات أزيل، وذاكرة التخزين المؤقت لنسخة PWA جديدة.

## ما لم يكتمل بعد (بدون ادعاءات)

- **الخرائط الحية**: لم تُنشأ أو تُنشر حتى الآن طبقة ECMWF/GFS حية؛ يلزم أولًا ملفا معايرة موثقان `tools/calibration/europe.json` و`levant.json`، وتجربة تحميل حقل GRIB حقيقي من NOAA، ثم السماح بالنشر. `data/map-products/catalog.json` فارغ عمدًا؛ لن تُعرض خرائط مختلقة.
- **ECMWF/ICON**: واجهة العرض تدعمهما، لكن أتمتة تنزيلهما وتحويل حقولهما لم تُربط بعد؛ أتمتة المشغل الحالية تخص GFS فقط.
- **عدد المدن**: الحزمة تتضمن 100 مدينة معروفة؛ توسيعها إلى 1000 يعتمد على تشغيل `npm run cities` مع GeoNames عند توافر الإنترنت.
- **الجرافيك الكرتوني لكل مدينة**: يولّد مشهدًا أصليًا ومختلفًا لكل مدينة؛ لا يعني وجود 1000 رسم أثري دقيق. للحصول على معالم محددة تحتاج قاعدة صور موثقة مرخصة.
- **بطاقة متحركة للتنزيل**: الحركة موجودة في معاينة الموقع؛ التصدير الحالي PNG ثابت، وليس فيديو/‏GIF.
- **الاختبار الخارجي**: اختبارات المتصفح أجريت مع بيانات طقس اصطناعية معزولة للاختبار فقط. لم تختبر منصة Cloudflare العامة أو الشبكة الحية بهذا البناء.

## طريقة نشر آمنة

1. أنشئ فرع GitHub جديدًا باسم `v6-review` بدل التعديل على `main` مباشرة.
2. افتح ملف **المشروع الكامل** وأضف محتوياته لجذر المستودع. إذا لديك مقالات أو خرائط أو أرشيف أضفتها بنفسك، **لا تستبدل** مجلدات `content/` و`data/` دون دمج ومراجعة.
3. افحص الملفات التي أزيلت من V5: `site/assets/v4.js` و`site/assets/games-v5.js` و`scripts/expand-studio-v5.py`؛ أصبحت غير مستخدمة. في فرع الترقية احذفها إن كانت موجودة.
4. شغّل `npm run build:offline` و`npm test` محليًا أو انتظر GitHub Actions `V6 code quality and build`.
5. افتح معاينة Cloudflare لفرع المراجعة. نفذ الاختبارات الحية لخرائط الصفحة، WebGL، وحفظ الصور من الهاتف.
6. ادمج الفرع في `main` بعد الفحص؛ لا يحتاج مشروع Cloudflare جديدًا.

إعدادات البناء: `npm run build`، وأمر النشر: `npx wrangler deploy`، والمجلد الناتج `dist`.

## اختبارات أُجريت

- `npm run build` — ناجح (مع الاحتفاظ بـ100 مدينة عند تعذّر GeoNames).
- `npm test` — 5 اختبارات ناجحة لهيكل الصفحات، وعدم نشر خرائط اصطناعية، وصحة حراسة ملفات الأمطار.
- `python tests/test_map_engine.py` — اختبار على بيانات تركيبية معزولة في TempDirectory لعدم تلوين البحر.
- `python tests/browser-v6-offline.py` — متصفح Chromium على قياسي 390 و1440 بكسل، لعبة الفضاء، سؤال أرصاد، التنقل، وتنزيل PNG؛ بلا أخطاء JavaScript أثناء الاختبار.
