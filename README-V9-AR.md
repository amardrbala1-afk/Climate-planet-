# كوكب المناخ — V9 (تصميم طقس المدن الجديد)

## ما تغيّر

- **16 أيقونة طقس SVG أصلية** بخلفيات شفافة، لا تستخدم Emoji أو روابط صور خارجية. تشمل الشمس، القمر، الغيوم، الأمطار، الرذاذ، الثلج، العواصف، الضباب، الرياح، ومؤشرات الحرارة والرطوبة وUV.
- **قسم طقس المدن أعيد بناؤه بصريًا:** بطاقة حالة حالية أكبر وأكثر وضوحًا، واسم المدينة والمصدر ووقت التوقع.
- **توقعات 7 أيام:** اختيار يوم يحدّث تفاصيل اليوم والبطاقة القابلة للتنزيل. عند اختيار يوم مستقبلي تظل بطاقة الطقس الرئيسية موسومة «الحالة الحالية» ولا يُخلط التوقع اليومي بحرارة الآن.
- **توقعات 24 ساعة كل 3 ساعات:** استخدام حقول `hourly` الحقيقية بما فيها كود WMO والليل والنهار والحرارة وفرصة المطر؛ لا تُعرض قيمة مجهولة كأنها متوقعة.
- **لوحة المؤشرات:** إعادة رسم بطاقات المحسوسة والرياح والرطوبة وفرصة المطر وUV مع وحدات ومصادر واضحة.
- **بطاقات النشر:** أربع هويات بصرية (سينمائي، مدينة، أرصاد، أضواء الغلاف) وصور PNG بأربعة مقاسات، مع تصدير WebM في المتصفحات الداعمة.
- تحسين نظام التحميل والأخطاء حتى لا تبقى قيم المدينة السابقة ظاهرة عند فشل الجلب.

## ملفات النسخة

- `site/index.html` — إعادة ترتيب واجهة طقس المدن، وإضافة عناصر العرض الحديثة.
- `site/assets/app.js` — إضافة WMO بالساعة وحالة التحميل وتحسين نص مؤشرات الخطر.
- `site/assets/v8-card.js` — إعادة بناء رسم البطاقة ومصدر الأيقونة وتكاملها مع تصدير PNG/WebM.
- `site/assets/v9.css` — تصميم الطقس الجديد المتجاوب.
- `site/assets/v9-weather.js` — ربط الواجهة بمصدر بيانات Open-Meteo.
- `site/assets/weather-icons-v9.js` — تحويل رموز WMO إلى أسماء الأيقونات.
- `site/images/weather-v9/*.svg` — مكتبة الرموز الجديدة (16 ملفًا).

## الحفاظ على الخرائط العددية

**لا تستبدل** `data/map-products/catalog.json` أو مجلد `site/images/maps/forecast/` أو `tools/` أو `.github/workflows/` عند ترقية الموقع المنشور. إصدار V9 الحالي هو تحديث بصري لطقس المدن، ولا يغيّر خط معالجة GFS الذي تم إصلاحه على GitHub.

استخدم ملف **V9_Upgrade** فوق مشروع GitHub الحالي فقط. النسخة الكاملة للأرشفة أو لإنشاء مشروع مستقل، ولا يُنصح برفعها فوق المستودع المباشر دون مراجعة اختلافات البيانات.

## النشر من GitHub Desktop دون نسخ ولصق كود

1. افتح GitHub Desktop ثم **File → Clone repository** إن لم يكن مستودع كوكب المناخ موجودًا على الكمبيوتر.
2. احتفظ بنسخة احتياطية من مجلد المستودع أو أنشئ فرعًا باسم `v9-review`.
3. فك ضغط ملف V9 Upgrade في مجلد منفصل، ثم انسخ **محتوياته** إلى جذر مجلد المستودع المستنسخ، مع اختيار استبدال الملفات المتطابقة والحفاظ على المجلدات.
4. من GitHub Desktop راجع التغييرات في Changes. لا يجب أن تظهر ملفات GRIB أو فهرس الخرائط أو Workflow ضمن تغييرات V9.
5. اضغط Commit إلى الفرع التجريبي، ثم Push origin. اختبر النشر، وبعد النجاح ادمج التغييرات في `main`.

أمر بناء المشروع: `npm run build`، واختبار محلي من دون تنزيل قائمة المدن: `npm run build:offline`.

## نتائج الفحص وحدوده

- اجتازت حزمة V9 اختبارات Node وصحة بنية SVG وتطابق معرفات HTML ومطابقة نظام WMO.
- نجحت اختبارات V6–V8 الخاصة بمعايرة الخرائط وسلامة منتجات GFS وعدم إدخال بيانات اصطناعية في فهرس الخرائط.
- لم ينجح فحص المتصفح المرئي في بيئة الإنتاج الحالية بسبب `ERR_BLOCKED_BY_ADMINISTRATOR` عند فتح الصفحات في Chromium؛ يلزم تجربة النسخة المنشورة على الهاتف/الكمبيوتر قبل اعتماد الشكل النهائي.
- لا يوجد اتصال مباشر بحساب GitHub، ولم تُعدّل نسخة الموقع المنشورة.
- رسومات المدن: **18 رسمًا لمعالم محددة** وباقي المدن مشاهد توليدية متنوعة، وليست صور معالم موثقة وفريدة لكل مدينة.

## مصادر البيانات

التوقعات اليومية والساعية: Open-Meteo Forecast API. تحترم الواجهة قيم المصدر كما وصلت، ولا تعرض الرسوم والمؤثرات كأنها رصد مستقل. حسب شروط Open-Meteo يجب مراعاة حدود وحقوق الاستخدام، خصوصًا عند استخدام الموقع تجاريًا.
