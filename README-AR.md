# كوكب المناخ | Planet of Climate 🌍

**نسخة تشغيلية أولية (V1)** لموقع علمي عربي مستقل، واجهة RTL متجاوبة، ونظام مقالات مع روابط مستقلة وصور معاينة لفيسبوك، وطقس مدن بلاد الشام، واستكشاف فضاء WebGL 3D، ومعرض خرائط، وأرشيف تاريخي قابل للتعبئة.

## ما الذي يعمل الآن؟

- واجهة احترافية متجاوبة للهاتف والحاسوب (HTML/CSS/JavaScript، بلا إطار عمل ثقيل).
- 3 مقالات **تعليمية تجريبية**، لكل واحدة عنوان URL مستقل ووسوم Open Graph لمشاركة الرابط في فيسبوك.
- دليل أولي يضم **100 مدينة وبلدة حقيقية** مدمجة بالملف `data/cities-seed.json`. البناء العادي مع اتصال إنترنت يحاول جلب بيانات **GeoNames** وإعداد قائمة حتى **1000 موقع حقيقي** في الدول الأربع دون اختلاق مدن.
- تحديث بيانات الطقس عند اختيار المدينة من **Open-Meteo**؛ الطلب يُخزن 10 دقائق بالجلسة لتجنب كثرة الاستدعاءات. عند فشل الشبكة لا تظهر قيم مخترعة.
- معرض خرائط ينشر الصور والتوصيف من خلال ملفات `content/maps/*.json`.
- تجربة 3D حقيقية بواسطة Three.js تُحمّل وقت دخول قسم الفضاء وتعرض الكواكب الثمانية مع معلومات أساسية.
- أرشيف مناخي يرتب الأحداث وفق السنة والبلد من ملفات `content/archive/*.json` مع دعم استيراد CSV.
- صفحات HTML ثابتة سريعة وملفات SEO من خلال `scripts/build.mjs`.

## الطريقة المفضلة: النشر على Cloudflare Pages وربطه بلوحة تحرير مجانية

1. أنشئ مستودعًا جديدًا في [GitHub](https://github.com/new)، ثم **فك ضغط أرشيف المشروع** وارفع ملفاته ومجلداته إلى جذر المستودع (لا ترفع ZIP نفسه كمستند). اجعل المستودع خاصًا أو عامًا وفق رغبتك. الملفات لا تحتوي مفاتيح سرية.
2. في [Cloudflare Dashboard](https://dash.cloudflare.com/) ادخل **Workers & Pages → Create application → Pages → Connect to Git**، واختر مستودع GitHub.
3. إعدادات البناء:
   - Framework preset: `None`
   - Build command: `npm run build`
   - Build output directory: `dist`
   - Root directory: جذر المستودع (`/`)
   - Node.js: إصدار حديث 20+ (22 مناسب).
4. نفذ Deploy. ستحصل على رابط `*.pages.dev` المجاني. أثناء البناء، يحاول المشروع استيراد **1000 مدينة** من GeoNames؛ إذا تعذر الاتصال بمصدر البيانات فسيستخدم 100 مدينة محلية فقط، ويمكن إعادة المحاولة بـ`npm run cities` في بناء لاحق.
5. يفضّل إضافة متغير بيئة **SITE_URL** بقيمة عنوان الموقع النهائي مثل `https://YOUR-PROJECT.pages.dev` لتوحيد روابط معاينات فيسبوك وملف sitemap. سيستخدم البناء `CF_PAGES_URL` تلقائيًا إذا لم تحدد `SITE_URL`.
6. افتح [Pages CMS](https://pagescms.org/) وسجّل الدخول بحساب GitHub المخوّل للوصول للمستودع، ثم اختر المستودع. يوجد ملف `.pages.yml` مهيأ لإدارة المقالات والخرائط والأرشيف، ورفع الصور إلى `site/images/uploads`.
7. أضف مقالًا من قسم **المقالات والنشرات**، ثم احفظه. التعديل سيحدث Commit في GitHub، فيُعاد بناء Cloudflare Pages. رابط المقال يصبح: `https://YOUR-PROJECT.pages.dev/articles/اسم-الملف/`، وعند مشاركته على فيسبوك يظهر عنوان المقال وملخصه وصورته بعد فحص معاينة الرابط. إن لم تظهر المعاينة مباشرة يمكن استخدام Facebook Sharing Debugger لإعادة فحص الرابط.

**تنبيه:** لا يمكن الكتابة تلقائيًا إلى صفحة فيسبوك بهذه النسخة. الرابط قابل للمشاركة يدويًا، والنشر التلقائي يتطلب إعداد صلاحيات Meta منفصلًا.

## إدخال بيانات الأرشيف الموجودة معكم

بإمكانكم إنشاء حدث تاريخي فردي من قسم «الأرشيف المناخي» في Pages CMS. أو لرفع مجموعة كبيرة:

1. جهّز ملف CSV بالأعمدة: `title,date,region,summary,image`.
2. استخدم رموز البلدان: `SY`, `JO`, `LB`, `PS` وتاريخًا بصيغة `YYYY-MM-DD`.
3. ضع الملف في مجلد `data/` ثم شغّل `node scripts/import-archive.mjs data/your-archive.csv` على الحاسوب، وارفع مجلد `content/archive` الناتج إلى GitHub؛ راجع صحة الأحداث قبل النشر.
4. ملف `data/archive-import-example.csv` مثال **شكلي لا يتضمن حدثًا تاريخيًا حقيقيًا**؛ لا تستورده للأرشيف العام.

## التشغيل المحلي

يتطلب Node.js 18+ (ويفضل 22). بعد فك الضغط:

```sh
npm run build:offline
npx serve dist
```

افتح عنوان الخادم المحلي. **فتح ملف index.html مباشرة من متصفح الملفات لا يفعّل طلبات JSON بشكل مضمون**، لذا استخدم خادم HTTP أو انشره على Cloudflare Pages. `npm run build` يحاول تحديث دليل المدن أولًا (يتطلب إنترنت).

## ترخيص مصادر البيانات وحدود المجانية

- [Open-Meteo](https://open-meteo.com/en/terms): الخطة المفتوحة للاستخدام **غير التجاري فقط** (منها المواقع بلا إعلانات أو اشتراكات)، وحدها 10,000 استدعاء/يوم و600/دقيقة وفق الشروط الحالية. تُعرض النسبة المصدرية أسفل وحدة الطقس. عند وضع إعلانات أو خدمات مدفوعة يلزم ترخيص مناسب، أو تبديل مزود البيانات.
- بيانات المدن: [GeoNames](https://www.geonames.org/) وفق CC BY 4.0؛ الترتيب وفق التعداد المعلن في المصدر، ويجب مراجعة أسماء المواقع ذات التسميات المحلية وأسمائها العربية قبل النشر العام.
- الاستضافة: Cloudflare Pages متاحة ضمن حدود [الخطة المجانية](https://developers.cloudflare.com/pages/platform/limits/). كثرة عمليات البناء وملفات الوسائط الكبيرة قد تستلزم تعديل البنية مستقبلًا.
- Three.js محمّلة من CDN عام؛ يلزم اتصال بالإنترنت لتفعيل المجسم.

## ملاحظات مهمة قبل إطلاق النسخة الرسمية

- صور الخرائط المعروضة بالواجهة حاليًا **رسم توضيحي فني وليس خرائط تنبؤات فعلية**. ارفعوا خرائطكم المرخصة من لوحة التحرير.
- الأرشيف التاريخي **فارغ عمدًا** حتى تزودونا بملف بياناتكم؛ لم تُختلق عواصف أو درجات حرارة تاريخية.
- هناك 100 موقع متاح في حزمة الرفع المباشر (dist)، و**حتى 1000** بعد استيراد GeoNames عند البناء المتصل. إن أردتم نشر نسخة ZIP مباشرة دون GitHub، فستحصلون على 100 مدينة حتى يُشغَّل الاستيراد.
- ينبغي قبل النشر العام ضبط الهوية البصرية النهائية، اسم النطاق، سياسة الخصوصية، والروابط الاجتماعية إن تغيرت.
