# كوكب المناخ — CLIMATE PLANET V5

ابدأ بقراءة **[دليل V5 الشامل](README-V5-AR.md)** للتركيب وألعاب الموقع الثلاث وأدوات خرائط النماذج وأساسيات التوثيق. 

**النشر:** `npm run build` ثم `npx wrangler deploy` عبر إعدادات GitHub المربوطة بـCloudflare، دون إنشاء مشروع جديد.

**حالة الخرائط العددية:** شاشة عرض وقاعدة بيانات وإعدادات معايرة ومحرك معالجة جاهزة، لكن إنتاج توقعات حقيقية يحتاج ملفات نموذج ومعايرة جغرافية دقيقة. لا تُنشر أي خرائط عددية اصطناعية ضمن الحزمة.
