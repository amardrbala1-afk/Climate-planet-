# كوكب المناخ — V5 | دليل التشغيل والنشر

**الإصدار:** 5.0 | **الواجهة:** عربية RTL | **النشر:** Cloudflare Workers Static Assets | **المصدر:** GitHub

## الميزات المنفذة

- **الصفحة الرئيسية:** تصميم متعدد الأقسام، وعناوين موجهة للقارئ، وتبويب مستقل «الألعاب العلمية».
- **ثلاث ألعاب حقيقية تعمل في المتصفح:** رحلة فضائية بمركبة تتحكم بها باللمس أو لوحة المفاتيح، تحدي المتنبئ الجوي بـ12 مسألة علمية مشروحة، وتجربة محاكاة للتعرية والجريان. الألعاب تعليمية مبسطة، وتعمل دون دفع أو حساب.
- **مختبر الفضاء:** العرض ثلاثي الأبعاد في بداية القسم، وبعده قائمة الأجرام ثم المقالات العربية المرتبة؛ تأكيد أن المقاييس والأحجام المدارية توضيحية وليست مقياسًا فلكيًا حقيقيًا.
- **المركز الجوي:** تبويبات مستقلة للخرائط العددية، توقعات المدن، ومكتبة الخرائط؛ الخريطة الأوروبية الأصلية لارتفاعات 500 هكتوباسكال وحرارة 850؛ خريطة بلاد الشام الأصلية لحرارة مترين والتراكم المطري، مع الزوم والانتقال والتعتيم واختيار النموذج/ساعة التوقع.
- **استوديو التصميم:** 34 قالبًا، و42 ملصقًا بخلفية شفافة، و6 مقاسات تنزيل PNG، وشعار بصيغة شفافة دون مربع أبيض.
- **المحتوى القديم:** المقالات، وأرشيف ثلوج القدس، وموسوعة الأجرام، والمدن، ومحرر المحتوى تظل ضمن الحزمة.

## حالة خرائط النماذج — تنبيه علمي مهم

**الأداة جاهزة لاستقبال البيانات العددية الموثقة، لكن لا تتضمن الحزمة توقعات GRIB حقيقية منشورة سلفًا**. يبدأ ملف `data/map-products/catalog.json` بقائمة فارغة عمدًا. تُعرض خلفية التضاريس دون رسم ملوّن مصطنع أو ادعاء أن التوقعات حية. لإنشاء أول خريطة حقيقية يجب إتمام الخطوات أدناه:

1. **المعايرة الجغرافية:** افتح صفحة المعايرة المستقلة `/tools/map-calibration.html` على الكمبيوتر، واختر الخريطة الأوروبية أو خريطة بلاد الشام. انقر 10–15 نقطة مرجعية مميزة منتشرة عبر الخريطة، وأدخل خطوط العرض والطول الخاصة بها (من مصدر جغرافي موثوق). صدّر `europe.json` أو `levant.json` إلى `tools/calibration/`. **لا تستخدم ملفات أمثلة الاختبارات كمعايرة حقيقية.**
2. **تحميل البيانات الخام:** حمل GRIB2 من NOAA NOMADS أو بيانات النموذج المتاح وفق شروط المصدر. أداة `tools/fetch_gfs.py` للتحميل الإداري الموجّه (لا تعمل أثناء فتح الزائر للموقع). مثال اختبار دون تحميل:

   ```bash
   python tools/fetch_gfs.py --date 20261120 --cycle 00 --forecast-hour 48 --region europe --field t850 --output model-data/t850.grib2 --dry-run
   ```

3. **تحويل النموذج إلى أعمدة** `lat,lon,value` مع وحدة موثقة واختيار زمن/ارتفاع صحيحين. مثال لملف GRIB2 بمتغير معروف بعد فحص محتواه:

   ```bash
   pip install -r tools/requirements-grib.txt
   python tools/grib_to_grid.py model-data/t850.grib2 model-data/t850.csv --variable t --level 850
   ```

   أسماء المتغيرات تتغير بحسب الترميز/المصدر؛ أمر `--variable t` مثال وليس ضمانًا. افحص metadata للملف أولًا. للهطول، **لا تستخدم مجموعًا تراكميًا من بداية تشغيل النموذج** إذا كنت تختار 6/12/18/24 ساعة؛ احسب الفرق بين تراكمين متوافقين من نفس التشغيل بعد التأكد من بيانات المدة في GRIB.

4. **إسقاط بيانات النموذج على خريطتكم:**

   ```bash
   python tools/render_map.py \
     --csv model-data/t850.csv --region europe --field t850 \
     --model GFS --run 2026-11-20T00 --forecast-hour 48 --unit K \
     --calibration tools/calibration/europe.json --source 'NOAA NOMADS / GFS'
   ```

   يتأكد المحرك من عدد النقاط وتغطيتها ومن RMSE المعايرة، ويرفض البيانات أو الوحدات غير الصحيحة. يقسم ألوان المطر إلى مربعات متجاورة، ويخفي الغطاء عن البحر باستنتاج حدود البحر من خلفية الصورة المرفقة. بعض الأخطاء الصغيرة ممكنة عند السواحل والجزر؛ يلزم فحص الخريطة قبل نشرها. خرائط طبقة 500 hPa تغطي البر والبحر، وحرارة 850 و2m والمطر تُعرض على البر.

5. **النشر:** يكتب الأمر صورة PNG شفافة داخل `site/images/maps/forecast/` مع بياناتها الموثقة في `data/map-products/catalog.json`. ارفع الصورة وملف الفهرس في GitHub؛ البناء اللاحق ينقل هذه الملفات إلى الموقع. **زر تنزيل الخريطة لا يُفعّل إلا إذا توفرت خريطة فعلية ومحددة المصادر.**

## تركيب الإصدار على المستودع الحالي

1. **نزّل نسخة احتياطية من المستودع الحالي، لا تمسح المقالات والخرائط التي أضفتها سابقًا.**
2. فك ضغط `Kawkab_AlMonakh_V5_Upgrade_Only.zip`، ثم ارفع **محتوياته مع المجلدات** إلى فرع `main` المرتبط بمشروع Cloudflare (وليس ZIP كملف واحد). بديل ذلك: استخدم الحزمة الكاملة لتكوين المستودع من البداية، بعد حفظ أي محتوى شخصي.
3. ترك إعدادات النشر: **Build command:** `npm run build`، **Deploy command:** `npx wrangler deploy`، **Root directory:** `/`.
4. راقب `Deployments` حتى Ready؛ ثم افتح الموقع وجرّب تبويبات الألعاب والخرائط والنشر، وحدّث المتصفح إن بقيت ملفات قديمة مخزنة.
5. إذا تعذر تنزيل بيانات GeoNames أثناء البناء، يستخدم الموقع البيانات المحلية الاحتياطية (100 مدينة). لا تدّعي حزمة المدن 1000 مدينة في الحالة الاحتياطية.

## تشغيل نسخة محلية

```bash
npm run build:offline
# استخدم خادم ملفات ثابتًا يقدّم المجلد dist
npx serve dist
```

## فحص الجودة

```bash
npm run build:offline
python tests/test_map_engine.py          # بيانات اختبار اصطناعية، لا تنشرها
python tests/validate-v5.py            # ملفات/مسارات/بيانات وعدد البطاقات
```

اختبار المتصفح الاختياري في `tests/browser-inline-v5.py` يستعمل استجابات وهمية محلية **للاختبار فقط**، ولا يتم شحنها للموقع؛ يلزم Playwright مع Chromium منفصل.

## مصادر البيانات وحقوق الاستخدام

- بيانات المدن الحالية: Open-Meteo، ضمن شروط الاستخدام والطلب وخطط الاستخدام التجاري.
- النموذج العددي: NOAA NOMADS GFS / ECMWF Open Data / DWD ICON عند الحصول على ملف مناسب، مع توضيح إصدار النموذج والمرجع.
- مكتبة الرسم Three.js، وموسوعة الفضاء العربية والمصادر كما في `SPACE-SOURCES.md`.
- Natural Earth land geometry بيانات مفتوحة/الملك العام؛ راجع `MAP-SOURCES.md`.
- الخلفيات التضاريسية من صور رفعها مالكو المشروع لهذا العمل؛ لا يتم جلبها من مزود خرائط خارجي.
- الألعاب تمثيلات تعليمية ولا تعتمد عليها لإصدار تحذيرات جوية أو تقديرات أخطار هندسية.

**هذه الحزمة مشروع قابل للرفع والاختبار محليًا وليست نشرًا تلقائيًا إلى GitHub أو Cloudflare.**
