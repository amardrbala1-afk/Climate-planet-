# 🌍 كوكب المناخ — الإصدار الرابع V4

**حزمة موقع فعلية قابلة للبناء على GitHub → Cloudflare Workers.** مبنية فوق V3 دون إلغاء نظام المقالات، أرشيف القدس، موسوعة الفضاء، صفحات المدن، أو إعدادات Cloudflare السابقة.

## التطويرات الفعلية

1. **الفضاء**: نقل اختيار الكواكب والأجرام إلى بداية صفحة الفضاء، ثم المشهد ثلاثي الأبعاد، ثم الشروح النصية المحفوظة داخل الموقع. إصلاح مربع الشمس باستخدام خامة توهج دائرية ذات شفافية فعلية. إضافة أسماء عربية فوق الكواكب، والتركيز على كوكب عند اختياره، والتقريب/الإبعاد بالأزرار وعجلة الفأرة وإيماءة الإصبعين، مع زر إعادة المشهد الكامل. السرعة قابلة للتغيير. بيانات ويكيبيديا العربية المحررة سابقًا محفوظة داخل `data/cosmos-v3.json`، ولا يلزم فتح ويكيبيديا لقراءتها. المحاكاة تعليمية لا تمثل المسافات والأحجام المدارية الحقيقية.
2. **مركز العمليات**: خلفية تضاريسية اختيارية **OpenTopoMap-R عبر openmaps.fr** مع خيار تبديل إلى خريطة OpenStreetMap؛ مع إسناد المصدر الظاهر. تظل القيَم عينات توقعات **19 مدينة محددة** من Open-Meteo؛ ليست خريطة حقل عددي متصل، وليست رادارًا. إضافة معرض خرائط النماذج ECMWF/GFS/ICON، ويعرض فقط صور الخرائط التي ينشرها محرر الموقع بنفسه مع النموذج والطبقة ووقت تشغيل النموذج وحقوق المصدر. روابط Météociel للرجوع إلى المصدر، **دون نسخ صور تلقائي**.
3. **طاقس المدن**: 18 رسم SVG مستضافًا داخل الموقع لتوضيح معالم/بيئات المدن، تظهر في شريط مدن مميزة وخلفية تقرير المدينة، مع رسم افتراضي عند عدم وجود معلم خاص. هذه رسومات **فنية تخطيطية** وليست صورًا محوّلة حرفيًا من الإنترنت ولا يجب التعامل معها باعتبارها توثيقًا معماريًا. خريطة أسماء المدن لم تغير إحداثيات الطقس الأصلية.
4. **استوديو بطاقات V4**: **18 قالبًا**: اليومي، الصباح، المساء، المطر، الرياح، الثلوج، الحرارة، البرد، الغيوم/الضباب، الملابس، التنقل، المدارس، الزراعة، النزهة، الرياح النشطة، مقارنة مدينتين، أرشيف القدس، والفضاء. **4 أحجام**: 1350×1080، 1080×1350، 1080×1920، 1080×1080. **4 مجموعات ألوان**. صور المدن الفنية، وشعار جديد شفاف PNG، مع بيانات المصدر والوقت على بطاقات الطقس. مقارنة المدن تجلب بيانات المدينة الثانية من Open-Meteo ولا تستخدم قيمة مختلقة.
5. **حزمة الملصقات**: 24 ملصق طقس ومناخ وفضاء، تُنشأ عند الضغط بصيغة PNG بخلفية شفافة. الملصقات **تصميمات توضيحية وليست تحذيرات رسمية**.
6. **الهوية**: شعار ذو خلفية شفافة في الرأس، الصفحة الرئيسية، البطاقات، والأيقونات PWA، مع تصميم متجاوب وإتاحة تقليل الحركة ودعم الأجهزة اللمسية. حُدّث رقم ذاكرة Service Worker إلى V4.

## رفع تحديث V4 على نفس الموقع

1. خذ نسخة احتياطية من مستودع GitHub الحالي، ولا تحذف المقالات والخرائط الشخصية.
2. **الأفضل**: استخدم الحزمة الكاملة V4، وفك ZIP ثم انسخ **محتوياته** إلى **جذر** مستودع GitHub. إذا أضفت في السابق محتوى خاصًا ضمن `content/posts` أو `content/maps` أو `content/jerusalem` فادمج الملفات ولا تستبدل محتواك دون مراجعة.
3. أو استخدم حزمة `V4_Upgrade_Only.zip` للملفات المعدّلة والجديدة فقط، وادمجها مع V3، مع الحفاظ على مسارات المجلدات.
4. اترك Cloudflare مربوطًا بنفس مستودع GitHub. إعدادات Worker السابقة:
   - Root directory: `/`
   - Build command: `npm run build`
   - Deploy command: `npx wrangler deploy`
   - `wrangler.jsonc` يحافظ على اسم Worker `climate-planet`؛ إن اختلف اسم مشروعك الفعلي فراجع الاسم أولًا.
5. عند ظهور **Ready**، أعد تحميل الموقع وافتح `/#space` و`/#operations` و`/#weather`.

### كيف تضيف خريطة نموذج إلى معرض العمليات؟

من Pages CMS → خرائط الطقس، ارفع ملف الصورة التي تملك حق استخدامها، وأدخل عنوان الخريطة، النموذج (`ECMWF` أو `GFS` أو `ICON`)، الطبقة، ساعة التوقع ووقت التشغيل، ومصدر الصورة. لا يضع الموقع اسم نموذج على صورة بلا بيانات تحريرية، ولا ينزل صور Météociel آليًا.

### بيانات الطقس والحقوق

- Open-Meteo: https://open-meteo.com/en/terms — استخدم البيانات وفق شروط الخدمة، بما فيها قيود الاستخدام المجاني غير التجاري. بيانات المحطات المباشرة غير مضمونة؛ القيم توقعات عددية.
- OpenTopoMap-R عبر openmaps.fr: https://openmaps.fr/tile-usage-policy.html — خريطة تبرعات/استخدام معتدل غير تجاري وفق سياسة المزود، ونسبة المصدر إلزامية. إذا كبر عدد الزوار، انتقل لمزود بلاطات مناسب.
- OpenStreetMap: https://operations.osmfoundation.org/policies/tiles/ — سياستها وحدودها مستقلة عن الإتاحة المجانية لبيانات OSM.
- Météociel: https://www.meteociel.fr/copyright/ — تجنب إعادة نشر الصور دون التحقق من الشروط؛ المعرض لا يسحبها.
- Solar System Scope: https://www.solarsystemscope.com/textures/ — خامات CC BY 4.0 تُحمّل عند الاتصال ويجب نسب المصدر.
- ويكيبيديا: انظر `SPACE-SOURCES.md` للحقائق المرجعية للأجرام الـ21، والمعلومات النصية داخل الموقع.

## اختبارات V4

- نجح `npm run build:offline` و `npm run build` محليًا (يستمر عند فشل اتصال GeoNames، ويستخدم 100 مدينة محلية موثقة بدل ادعاء اكتمال 1000 مدينة).
- نجح تحليل ملفات JavaScript بـ`node --check`، وتحقق تنظيم صفحات HTML وقراءة رسوم SVG الـ18 كـXML، ونجح اختبار بنية V3 (21 جرمًا و86 سجلًا شتويًا تاريخيًا).
- **قيود الاختبار**: لم يُنجز اختبار تفاعلي بصري داخل المتصفح بسبب سياسة بيئة المتصفح التي تمنع حتى عنوان الخادم المحلي (`ERR_BLOCKED_BY_ADMINISTRATOR`). لذا يجب تجربة WebGL، تنزيل الصور، تحميل بلاطات الخريطة، واستجابة Open-Meteo على موقعك المنشور قبل اعتبارها مختبرة لدى المستخدم.
- لا يوجد نشر تلقائي إلى حساب GitHub أو Cloudflare من هذه الحزمة.

## الملاحظات العلمية

- ملصقات الحرارة والرياح والثلوج لا تعد تحذيرات رسمية، وملصق المدارس لا يتضمن قرارات تعطيل.
- الأرشيف بعد 2019 غير مستكمل بالكامل. لا تعرض سنوات بلا بيانات باعتبارها سنوات بلا ثلوج.
- معالم المدن مخططات فنية أصلية مستلهمة من طابع المكان، لا بدائل دقيقة للصور الحقيقية.
