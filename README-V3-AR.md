# 🌍 كوكب المناخ — CLIMATE PLANET V3

**تطوير جاهز للبناء على Cloudflare Workers من مستودع GitHub.** يحافظ على أسلوب V2 والشعار الأصلي والأرشيف وملفات المقالات.

## ما نُفّذ فعليًا؟

1. **مركز العمليات الجوية** — صفحة مستقلة `/#operations` فيها خريطة Leaflet بأساس OpenStreetMap (عند توفر CDN/البلاطات)، عينة **19 مدينة حقيقية محددة الإحداثيات** من سوريا والأردن ولبنان وفلسطين. طبقات نقطية لدرجة الحرارة العظمى والهطول اليومي وسرعة الرياح القصوى، مع اختيار **7 أيام** وتحريك الأيام، وتحميل التوقعات من **Open-Meteo** بطلب واحد متعدد الإحداثيات وتخزين لمدة 45 دقيقة في جلسة المتصفح. **ليست** خريطة شبكة ECMWF/GFS أو رادار أو قياسات محطات. إذا فشل الإنترنت لا تظهر أرقام مخترعة.
2. **طقس المدن المحسّن** — بيانات الساعات القادمة (منحنى حرارة واحتمال مطر)، أداة تنزيل بطاقة 1350×1080 بشعار كوكب المناخ ووقت البيانات، حفظ مدينة في مفضلة المتصفح، وإمكانية مقارنة **ECMWF** و**GFS** باختيار المستخدم (درجات الحرارة القصوى، عند توفر واجهتي النموذجين). بقي نظام الملابس ومؤشرات النقل والمدارس والصحة الاسترشادي من V2 مع توضيح حدوده.
3. **موسوعة فضاء عربية داخل الموقع** — **21 جرمًا**: ثمانية كواكب وأربعة أقمار وثلاثة نجوم وثلاث مجرات ومحطتان فضائيتان وتلسكوب جيمس ويب. لكل جرم عنوان، مقدمة، شرح للخصائص والظواهر والرصد، و«هل تعلم؟». جميع النصوص **محفوظة في `data/cosmos-v3.json` وتعرض مباشرة داخل الموقع** بلا حاجة لفتح ويكيبيديا. قائمة المصادر والمقالات المستند إليها في `SPACE-SOURCES.md`. المجسم ثلاثي الأبعاد يستخدم Three.js وخامات Solar System Scope عند الاتصال؛ أحجام الكواكب وسرعة دورانها توضيحية. يمكن البحث في أسماء الأجرام واختيار جرم عشوائي.
4. **مرصد أرشيف القدس** — استمرار الأرشيف التاريخي 1950–2026 الموجود في V2 من Arab4Climate، مع **مخطط أعلى 12 تراكمًا لحالات منفردة** وأداة مقارنة موسمين بحسب أعلى تراكم موثق وعدد السجلات. يبقى غياب السجل «غير موثق» وليس صفرًا، وبيانات السنوات الحديثة غير مكتملة.
5. **منشورات وخرائط** — استمرار خطوط النشر والتحرير من V2 دون حذف المحتوى الموجود، وروابط مقالات Open Graph المناسبة لفيسبوك، مع إصلاح رابط العودة لقسم المقالات.
6. **البحث + تطبيق الهاتف** — بحث شامل داخل المقالات والخرائط ومدن الدليل وموسوعة الفضاء؛ حفظ المفضلات محليًا، وManifest + Service Worker لذاكرة ملفات الواجهة (لا يخزن التوقعات كما لو كانت مباشرة).
7. **أداء وتجربة الاستخدام** — طبقات منفصلة لميزات V3، تصميم متجاوب، مراعاة تقليل الحركة، وحزم ملفات ثابتة بدون خادم حسابات مدفوع.

## حدود معلنة

- **الخرائط**: تمثل 19 نقطة جغرافية وليست خرائط تنبؤ شبكية أو رادارًا، وتعتمد على مكتبة Leaflet وبلاطات OpenStreetMap المتاحة من الإنترنت. تجنب الاستخدام المكثف لبلاطات OSM الرسمية؛ عند التوسع استخدم مزود بلاطات مناسب.
- **الموسوعة**: المحتوى الأصلي بالعربية مبني على حقائق من مقالات ويكيبيديا المحفوظة في جدول المصادر. لا يوجد نسخ آلي حي لويكيبيديا، ولا تواصل معها في زيارة الزائر.
- **الطقس**: واجهة Open-Meteo المجانية للاستخدام غير التجاري فقط، وبحدود استخدام وشروط نسب. قد لا تكون بعض المتغيرات متاحة لجميع نقاط البيانات/النماذج. لا تستخدم مؤشرات المدارس/الصحة/التنقل كقرارات رسمية.
- **الأرشيف**: المصدر المعتمد يمتد تاريخيًا إلى 2019 تقريبًا؛ السنوات 2020–2026 موجودة كنطاق أرشفة، لا كحالات مثبتة.
- **المدن الألف**: ملف `data/cities.json` يحتوي قائمة احتياطية من 100 مدينة تقريبًا؛ عند تشغيل `npm run build` تحاول أداة GeoNames تحديثه إلى 1000 موقع، وإذا تعذر الاتصال يحتفظ بالبيانات المحلية. لا يُعرض عدد وهمي.
- **المدونة**: لا تزامن تلقائي مع فيسبوك. المشاركة اليدوية للروابط فقط.

## طريقة تحديث الموقع المنشور (GitHub → Cloudflare)

1. احتفظ بنسخة احتياطية من المستودع قبل استبدال الملفات.
2. فك الضغط وارفع **محتويات** ملف V3 إلى **جذر** المستودع الحالي (الملفات والمجلدات، لا ترفع ZIP وحده). اترك المقالات والخرائط الخاصة التي أضفتها ضمن `content/` كما هي وادمجها بدل حذفها.
3. الإعدادات الصحيحة: **Root `/`**، **Build `npm run build`**، **Deploy `npx wrangler deploy`**، الفرع `main` (إن كان مستخدمًا عندك).
4. الملف `wrangler.jsonc` مضبوط على Worker باسم **`climate-planet`** بناءً على اسم مشروعك الظاهر في الصورة. إذا كان الاسم الفعلي مختلفًا، يجب تعديله قبل النشر إلى اسم Worker نفسه حتى لا يُنشأ مشروع آخر.
5. تعيين متغير بناء اختياري `SITE_URL=https://climate-planet.climateplanet.workers.dev` للروابط الأساسية وبيانات المشاركة، أو عدّل القيمة الافتراضية في `scripts/build.mjs`.
6. بعد ظهور **Ready** افتح الرابط، وجرّب `/#space` و`/#operations` و`/#weather` و`/#archive`. بعد تحديث ملفات Service Worker قد تحتاج تحديث الصفحة أو إعادة فتح التبويب.

### التشغيل

```bash
npm run build:offline  # بناء دون تنزيل تحديث قائمة المدن
npm run build          # بناء مثل Cloudflare مع محاولة تحديث المدن
npx wrangler deploy    # يحتاج إعداد/اتصال Cloudflare
```

**مواضع تعديل المحتوى**:
- المقالات: `content/posts/*.md`
- الخرائط: `content/maps/*.json`
- الأرشيف الإضافي: `content/jerusalem/*.json`
- موسوعة الفضاء: `data/cosmos-v3.json`
- طقس المدن: `data/cities.json`
- خرائط العينات: `site/assets/operations.js`، ثابت `SITES`.
