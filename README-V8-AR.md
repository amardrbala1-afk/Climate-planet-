# كوكب المناخ V8 — Climate Planet

**الإصدار:** 8.0.0 | **الاستضافة:** Cloudflare Workers Static Assets | **المصدر:** GitHub

## ماذا تغير؟

### الخرائط العددية: GFS من +0 إلى +72

- يعتمد خط الإنتاج على بيانات **NOAA/NOMADS GFS 0.25°** مع معايير تحقق صارمة (الدورة الزمنية، المستوى، نوع المتغير والوحدة).
- يغطي توقعات +0 إلى +72 ساعة، بخطوة **6 ساعات**: 13 إطارًا لكل طبقة آنية (ارتفاعات 500 hPa، حرارة 850 hPa، حرارة مترين).
- المطر: 12 خريطة لتراكم كل فترة 6 ساعات، تنتهي عند +6، +12… +72. ليست هناك خريطة تراكم لساعة +0.
- يولّد فوق ذلك خرائط تراكم 12 ساعة (11 خريطة)، 24 ساعة (9)، 48 ساعة (5)، 72 ساعة (1): **26 صورة إضافية**.
- الإجمالي: **77 صورة** للدورة الكاملة (39 + 12 + 26). إنشاء هذه الصور يحتاج تشغيل مهمة GitHub Actions على شبكة متصلة ببيانات NOAA. **لا تتضمن الحزمة صور توقعات مستقبلية مصطنعة**.
- تراكميات الهطول تُجمع من شبكات GRIB التي جرى التحقق منها، بعد مطابقة الإحداثيات، ولا تُجمع من مربعات ألوان الصورة.
- يحتفظ بمعالجة التكرارات المتطابقة لسجلات APCP من V7، ويرفض مصادر المطر المتعارضة.
- يعتمد ملفات الإسناد `.pgw` الأصلية لخريطتي أوروبا وبلاد الشام، والبحر محجوب من الطبقات السطحية.
- لا ينشر دفعَة غير مكتملة؛ إذا فشل أي إطار يوقف المهمة قبل `git push` ويُبقي آخر بيانات منشورة.

### واجهة الأطلس

- شريط الساعات مع الحركة وإيقافها وتغيير السرعة.
- اختيار فترة مطر 6، 12، 24، 48، 72 ساعة (بحسب الإطارات الموجودة في الفهرس).
- عرض حالة اكتمال الإطارات، مع تمييز الساعات غير المنشورة.
- عرض طبقتَي 500 و850 hPa معًا، ومقارنة تشغيلين عند توافر البيانات.
- النقر على الخريطة لعرض الإحداثيات ونقطة مرجعية إضافية من Open-Meteo GFS؛ يُكتب بوضوح أن تحديث النقطة قد يختلف عن دورة NOAA المعروضة.
- تصدير تسلسل الخرائط بصيغة WebM في المتصفحات التي تدعم MediaRecorder وCanvas captureStream، مع مصدر النموذج على الفيديو.

### طقس المدن والبطاقات

- عرض تفاصيل التوقع حسب اليوم المختار (العظمى، الصغرى، الهطول، الهبات)، ومواعيد الشروق والغروب، ومقارنة مدينة ثانية.
- «أبرز مدن اليوم» من المدن المتاحة في الدليل. يتطلب الوصول إلى Open-Meteo.
- ثلاثة تصميمات للبطاقة: **سينمائي**، **مجسم المدينة**، **أرصاد احترافية**، أربعة مقاسات، شارة كوكب المناخ الشفافة، وتاريخ حقيقي من التوقع.
- رسوم معالم محلية جاهزة للمدن المختارة، ومشاهد رسوم متمايزة للمدن غير المختارة؛ **ليست هناك معالم أثرية موثقة لكل مدينة في القائمة**.
- تحريك المطر والثلج والسحب في المعاينة، وتصدير PNG ثابت وWebM قصير عند دعم المتصفح.
- يظل دليل 100 مدينة هو الاحتياطي المحلي؛ توسعته عبر GeoNames تتطلب اتصالًا شبكيًا وقت البناء.

### الألعاب

- تطوير مظهر لعبة الفضاء ورسومها ومهامها.
- زيادة أسئلة تحدي الأرصاد مع مستويات وتفسير الإجابات ورسوم تعليمية، والإبقاء على لعبتين دون لعبة الجيولوجيا.

## تشغيل مهمة الخرائط في GitHub

1. احتفظ بنسخة احتياطية من مستودعك (GitHub → Code → Download ZIP).
2. استخدم **حزمة الترقية فقط** إذا كان موقعك الحالي على V7، ولا تستبدل `data/map-products/catalog.json` أو صور `site/images/maps/forecast/` الحالية، لأنها تحمل خرائطك المنشورة.
3. ارفع الملفات داخل جذر المستودع **بالمسارات نفسها** (وخاصة `.github/workflows/forecast-main.yml` و`tools/` و`site/assets/`). ملف ZIP لا يُفك تلقائيًا إذا رفعته كملف واحد إلى GitHub.
4. إذا وُجد ملف قديم `.github/workflows/forecast-maps.yml`، احذفه من GitHub حتى لا تعمل مهمتان في الوقت نفسه. هذا الإجراء ضروري لمنع التداخل بين إصدارات V7 وV8.
5. من **Actions** افتح `V8 · NOAA GFS 72-hour forecast atlas`، واضغط `Run workflow` واختر `main` و`72`.
6. عند اكتمال المهمة تحقق من سجل `Render source-verified 72-hour forecast sequence` ومن الرسالة `V8_COMPLETE` ونجاح `Publish only complete verified batch`.
7. بعد نجاح Commit، افتح Cloudflare → Deployments وتحقق من بناء الإصدار الجديد، ثم اختر نموذج **GFS** في الأطلس. ظهور زر نموذج ECMWF لا يعني وجود تحديث آلي له؛ المنتج الحي المربوط في هذا الإصدار هو GFS.

### أوامر الاختبار محليًا

```bash
npm run build:offline
npm test
python tools/schedule_gfs.py --dry-run --hours 72
```

أمر `npm run build` يحاول مزامنة مدن GeoNames ثم يبني، وقد يعود إلى قائمة المواقع المحلية إذا لم يتوفر اتصال شبكة.

## ملاحظات علمية وتشغيلية

- فاصل 6 ساعات بين إطارات العرض لا يعني أن نموذج GFS لا يوفر ساعات أخرى؛ هو اختيار تصميمي لخفة التصفح والنشر.
- بدء تراكم المطر في +6 دون +0 صحيح: صورة +6 تعني كمية الساعات 0–6، وصورة +72 ذات 72 ساعة تعني 0–72.
- إذا فشلت أي رسالة GRIB من NOAA أو تعارضت بيانات APCP أو لم يكتمل فهرس 77 صورة فلن يُنشر الإصدار الجديد، وتبقى آخر سلسلة مكتملة سليمة؛ سجل Actions سيعرض سبب الفشل.
- مهمة V8 قد تستغرق وقتًا وتستهلك دقائق GitHub Actions وشبكة NOAA؛ تعمل تلقائيًا مرتين يوميًا بعد إضافتها.
- **Open-Meteo**: تحقق من شروط استخدام المصدر للاستخدام غير التجاري والحدود المفروضة على الاستدعاءات قبل عرض الإعلانات بالموقع.
- **بطاقات WebM** ليست MP4؛ إن كان متصفح الزائر لا يدعم التسجيل يبقى PNG متاحًا.
- لم ينشر هذا المشروع تلقائيًا على حساب GitHub الخاص بك؛ لا نملك إذن الكتابة على المستودع ضمن بيئة إنشاء الملف.

### ملفات مهمة

- `.github/workflows/forecast-main.yml`: مسار الإنتاج الدوري اليدوي والآلي
- `tools/schedule_gfs.py`: تنسيق 77 خريطة والتحقق منها
- `tools/publish_gfs.py`: تنزيل حقل واحد والتحقق منه من NOAA
- `tools/aggregate_rain.py`: جمع تراكمات المطر الخام
- `tools/render_map.py`: إسقاط البيانات على الخرائط الأصلية
- `site/assets/v8-maps.js`, `site/assets/v8-city.js`, `site/assets/v8-card.js`, `site/assets/v8.css`: أدوات V8 في المتصفح

## التحقق الذي تم

نجح بناء الموقع، وفحوصات Python البرمجية، ومعايرة الخرائط والبحر، واختبارات واجهات Chromium للهاتف (390px) والكمبيوتر (1440px) باستخدام بيانات اختبار معزولة **لا تدخل ملفات الإنتاج**، وتنزيل PNG بحجم 1080×1350. لم يجر اختبار تشغيل دورة NOAA الحية كاملة في هذه البيئة.
